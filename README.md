# Kickstarter Data Analytics
End-to-end Kickstarter data analytics project using Excel, SQL, Power BI, and Tableau.
## Project Overview

This project analyzes Kickstarter crowdfunding data using multiple data analytics tools.

The analysis focuses on project performance, funding, backers, categories, countries, and project trends.

## Tools Used

- Excel
- SQL
- Power BI
- Tableau

## Key Analysis Areas

- Project success and failure
- Funding and funding goals
- Backers analysis
- Category performance
- Country-wise performance
- Project trends
- Successful project analysis
- Funding patterns
- Business KPIs
