# Kickstarter Data Analytics

## Project Overview

This project analyzes Kickstarter crowdfunding data to understand project performance, funding patterns, backer behavior, categories, countries, and overall project trends.

The project demonstrates an end-to-end data analytics workflow using Excel, SQL, Power BI, and Tableau.

The analysis focuses on understanding why projects succeed or fail, how much funding projects receive compared with their goals, and how different categories and countries perform.

## Business Questions

The analysis explores questions such as:

- How many projects are successful, failed, or cancelled?
- What is the relationship between funding goals and actual funding?
- Which categories perform the best?
- Which countries have the highest number of projects?
- Which projects receive the most funding?
- How do successful projects differ from unsuccessful projects?
- How does the number of backers affect project success?
- What funding patterns can be identified?
- What trends can be observed across Kickstarter projects?

## Key Analysis Areas

### Project Performance
Analysis of successful, failed, and cancelled Kickstarter projects.

### Funding Analysis
Comparison of project funding goals with the amount actually raised.

### Backers Analysis
Analysis of backer participation and its relationship with project performance.

### Category Analysis
Comparison of Kickstarter categories to identify stronger and weaker performing areas.

### Country Analysis
Analysis of project distribution and performance across different countries.

### Trend Analysis
Identification of project and funding trends across the available data.
